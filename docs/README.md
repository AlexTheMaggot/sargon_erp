# Карта документации SHENOLL

Актуализация: 2026-10-09. Основание — локальные исходники и согласованные требования
из обсуждения проекта. При подготовке этих документов код, база данных и внешний
сервер не изменялись; тесты и развёртывание не запускались.

## Источники и актуальность

1. Фактическое поведение определяется исходниками и применёнными в конкретном
   окружении миграциями. Документы помогают ориентироваться, но не заменяют проверку.
2. Согласованное требование и текущая реализация — разные вещи. Если они расходятся,
   обозначьте расхождение и уточните важное решение, а не исправляйте код молча.
3. В `DECISIONS.md` различаются требования пользователя, наблюдаемая реализация
   и отложенные возможности. Отложенная возможность не является поручением.
4. `ERRORS.md` — исторический отчёт с датами и статусами исправлений. Не считайте
   каждое старое замечание текущей ошибкой и не переписывайте историю результатов.
5. Не фиксируйте утверждение «всё работает» без указания выполненной проверки.
   Наличие автоматического теста не означает, что он был запущен в текущей задаче.

## Как поддерживать документы

| Изменение | Обновить |
| --- | --- |
| Компоненты, модели, транспорт данных, API | `ARCHITECTURE.md` |
| Статусы, расчёт объёмов/стоимости, ограничения | `BUSINESS_RULES.md` |
| Модули, права, административные исключения | `ACCESS_CONTROL.md` |
| Тесты, команды и проверочные сценарии | `TESTING.md` |
| Новое значимое согласованное решение | `DECISIONS.md` |
| Запуск проекта или общие инструкции агенту | Корневые `README.md` / `AGENTS.md` |

После обновления сверяйте внутренние ссылки, имена моделей, коды модулей и маршруты.
Не поддерживайте несколько независимых полных описаний одного правила.

## Границы

- Документация разработчика в `docs/` и статьи пользовательской базы знаний
  в PostgreSQL — разные источники. Изменение Markdown не обновляет статьи в БД.
- Здесь нет паролей, JWT, значений `.env`, адресов внешнего сервера и данных поставщиков.
- Состояние групп после seed-миграций не гарантирует их текущее состояние в БД:
  администратор может изменять настройки.
- `AGENTS.md` уже исключён из Git. Остальные новые документы текущим `.gitignore`
  не исключены. Коммит и публикация в рамках этой задачи не выполняются.
- `TODO.md` не создаётся: пользователь ранее решил работать точечно.
